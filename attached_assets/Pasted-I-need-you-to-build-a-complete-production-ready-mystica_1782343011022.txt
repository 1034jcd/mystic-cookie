- playTone(freq, duration, type, volume) function
- playCrack() - plays 3 tones for cracking sound
- playReveal() - plays mystical chimes (C, E, G notes)
- playPurchase() - plays coin sound
- Toggle sound on/off

## Particles
- 30 floating gold particles with random sizes, positions, animation durations

## Fortune Generation
- Load fortunes from /api/fortunes
- Filter by selected category (love, career, health, wealth, wisdom)
- Random selection when cookie is cracked
- Crack animation (scale + rotate)
- Coin particles falling
- Fortune reveal animation (scale up + fade in)

## Payment Flow
1. User clicks "Crack Cookie" button
2. Call /api/payment/chime to get payment details
3. Show payment modal with QR code and $jduvall info
4. User pays via Chime (outside app)
5. User clicks "I Paid" button
6. Call /api/verify-payment to log payment and send email
7. Reveal fortune
8. Save to collection in localStorage

## Collection
- Save fortune + date + category to localStorage
- Display in modal with export functionality
- Export as text file

## Stats
- Track total cookies cracked
- Track total spent ($0.99 per fortune)
- Track daily streak
- Update in real-time
